# Хранилище нотаций BPMN

Централизованное хранение, версионирование и совместная работа
с утверждёнными моделями бизнес-процессов в нотации BPMN 2.0.

## Структура
- 01_approved — утверждённые нотации
- 02_draft — черновики и доработка
- 03_archive — выведенные из действия процессы
- _docs — регламент и реестр процессов

## Правила именования
pNN_kratkoe_imya.bpmn (латиница, нижний регистр, без пробелов)

## Порядок внесения изменений
1. Создать ветку вида feature/pNN-opisanie
2. Внести правки в Camunda Modeler и зафиксировать коммит
3. Открыть Pull Request и назначить рецензента
4. После согласования — слияние в main
